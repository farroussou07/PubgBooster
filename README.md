# PUBG Ultra Booster ⚡

تطبيق أندرويد مفتوح المصدر وخفيف جداً، يستغل صلاحيات **Shizuku API** لتفعيل أعلى أداء ممكن في الألعاب (144Hz، 120 FPS، وتثبيت البينغ) دون الحاجة لروت.

## المميزات
- 🎮 فك قفل الشاشة إلى 144Hz ومنع هبوطها أثناء اللعب.
- ⚡ إجبار وضع الألعاب على 120 FPS (Game Mode Override).
- 🌐 تثبيت البينغ وتفعيل خادم Cloudflare Gaming DNS لمنع التذبذب.
- 🛡️ إزالة قيود وتخفيض حرارة Joyose و Powerkeeper في أجهزة شاومي وريدمي.
- 🚀 زر تعزيز شامل بضغطة واحدة (One-Click Boost).

## طريقة البناء على GitHub وتحميل الـ APK:
1. قم بإنشاء مستودع جديد على حسابك في **GitHub** (New Repository).
2. ارفع ملفات هذا المجلد إلى المستودع.
3. توجه إلى تبويب **Actions** في مستودعك، ستجد أن البناء بدأ تلقائياً عبر سيرفرات GitHub.
4. بمجرد انتهاء البناء (علامة صح خضراء ✓)، ستجد ملف الـ **`PUBG-Ultra-Booster-APK`** جاهزاً للتحميل المباشر وتثبيته على الهاتف!
